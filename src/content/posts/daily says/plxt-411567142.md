刚刚完成了一件特有成就感的事——**给我的网站装上了评论系统**，因此写篇日志记录一下。

## 一、为什么要做评论

这个问题很好回答，人是群居动物，既然是群居动物，必然少不了的就是交流。

之前我试过用 GitHub 的方案搭评论，结果发现**弊端非常大**：

- 访客**必须登录 GitHub 账号**才能评论
- 国内访问 GitHub 不稳定，**要开加速器**
- 我身边的朋友里，根本没人有 GitHub 账号

说白了，这套评论系统**只有程序员能用**。而很多人可能连 GitHub 是什么都不知道。

所以我想做一套**谁都能用**的评论系统：
- 不用注册账号
- 不用翻墙
- 填个昵称就能说话

![](https://1815356055.cdn.123clouddisk.com/1815356055/yk6baz03t0l000dlnm5r5q44bmbzaua5DIYPAIDyAqayAGxzDdU0Dqe=.png)
虽然在“提交”按钮旁边有一个“登录”，但其实不登录也照样可以发表评论。

## 二、为什么最后是 Waline

评论系统的方案其实挺多的，我一开始看中了一个叫 Twikoo 的，界面简洁、功能也够。

但研究了一圈发现：**Twikoo 官方不支持我网站用的那套云服务**。虽然社区有第三方适配，但稳定性没保证，我不想以后出问题。

后来换成了 **Waline**。
![](https://1815356055.cdn.123clouddisk.com/1815356055/ynf1no03t0l000dlnm5pw0gtuqbz37mpDIYPAIDyAqayAGxzDdU0Dqe=.png)
Waline 和 Twikoo 是同类产品，都是"匿名评论系统"，但 Waline 有一个成熟的社区方案，可以完美跑在 **Cloudflare** 上——而我的网站暂时就部署在 Cloudflare，等于说**一个账号搞定所有事情**。

最重要的是日后购买了自己的服务器，自己的域名，要迁移评论也很容易。这套系统本身就支持直接导入导出评论。

还有就是：
- **完全免费**（Cloudflare 的免费额度对个人博客来说绰绰有余）
- **国内可访问**（Cloudflare 有国内节点）
- **访客不需要注册**（填昵称 + 邮箱就能评论）
- **数据在我自己手里**（存在我自己的 Cloudflare 账号里，不经过任何第三方平台）

总之很超乎我的预期。
